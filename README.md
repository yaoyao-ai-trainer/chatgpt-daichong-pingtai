## 一、先弄清 5 个词

- **代充**：你付人民币，平台用它自己的海外付款渠道，把会员开到你自己的 ChatGPT 账号上。代充不是 OpenAI 官方渠道。
- **卡密 / 激活码**：付款后拿到的一串码，到平台的充值页输入后自助开通。没开通前，它就是一张"待使用的券"。
- **Session（登录信息）**：登录 chatgpt.com 后，在 chatgpt.com/api/auth/session 页面看到的一段文字。多数代充平台用它开通会员。它不是密码，但同样敏感，只能交给你下单的那个平台。
- **掉会员 ≠ 封号**：掉会员是账号还能登录、只是变回免费版；封号是登录不了，或收到官方停用邮件。多数平台只保前者。
- **境外 Invoice ≠ 增值税发票**：Invoice 是海外常见的消费凭证，国内单位报销一般要增值税发票，买之前先问清你们财务收哪种。
